# 使用指南

状态：现行
摘要：安装后的浏览、下载、采集、身份、代理、资料库、录制和设置操作。

## 安装

安装包没有开发者签名。

macOS 把应用放入“应用程序”后执行：

```bash
xattr -dr com.apple.quarantine /Applications/抖音台.app
```

再右键应用选择“打开”。Windows 在 SmartScreen 中点击“更多信息 → 仍要运行”。

也可以按 [BUILD.md](BUILD.md) 自行编译。

Windows 的 WebView2 与可选 HEVC 扩展安装、卸载方法见 [Windows 播放组件](WINDOWS-MEDIA.md)。安装或卸载扩展后请从托盘完全退出，再重新打开应用。

## 首次启动

应用直接在本机运行，不需要填写服务器地址或令牌。启动后进入推荐流，右侧状态显示“已连接”。

不登录抖音账号也可以浏览、下载和采集。需要账号会话的能力按页面提示处理。

首次启动会在本机生成匿名设备身份。新身份会先经过平台的新设备风控期，通常 1–2 天后恢复；期间直播和评论可能提示稍后重试。

## 浏览

左侧“发现”提供推荐、热榜、直播、短剧、收藏和历史。

- 点击卡片进入播放页。
- 播放页内滚轮或右侧按钮切换上一条、下一条。
- 作者区打开用户主页。
- 搜索支持视频、用户、短剧和话题分栏。

## 粘贴链接

点击顶部“粘贴链接”或按 `Ctrl+V`。

支持分享文本、短链、视频、用户、直播、短剧、合集、话题和裸 ID。解析后先显示确认卡，确认后再创建任务。

多链接可批量粘贴。类型、日期、数量和单文件上限可在确认框过滤。

## 下载

1. 在作品、用户、话题或合集页选择内容。
2. 打开下载或批量下载。
3. 选择画质、原声、封面等可选项。
4. 确认入队。

下载中心支持暂停、继续、重试、取消和并发调整。已完成内容按资料库路径跳过，同名文件自动追加序号。

关闭应用后任务写入数据库，重新启动会恢复队列；分片文件支持续传。

## 采集

采集用于保存全字段 JSONL、评论和批量结果。

- 单条采集从卡片或播放页进入。
- 采集中心可创建一次性任务、批量任务和定时计划。
- 任务可以暂停、继续、忽略和查看结果。
- 评论导出写入资料库。

接口返回空或触发限流时应用会换身份重试。连续失败时查看任务错误和设置页能力状态。

## 身份

设置页“身份”显示本机身份数量和健康状态。

- 目标数量决定可用身份的维持水位，范围 1–128。
- 暂停后停止补充，已经可用的身份仍可租用。
- 重建会清空本机名单并从头生成，旧身份立即停用。
- 身份只保存在本机，不随安装包分发。

## 出口代理

左侧导航“代理”用于当前网络被接口限流时接入自备出口。

- 每行一个地址，支持 `host:port`、`http://` 和 `socks5://`。
- 默认关闭，关闭或列表为空时全部直连。
- 只有抖音接口走代理，视频和图集默认仍走 CDN。
- 仅当 CDN 也拉不动时打开“CDN 也走代理”。
- `实测全部` 只检查连通和耗时，不改已生效配置。

## 资料库

资料库汇总已下载、已采集和评论记录。

- 按类型、时间、名称或作者筛选。
- 切换网格和列表。
- 打开文件、目录或系统回收站。
- 删除文件和移除记录分开处理。

下载或采集完成后内容才会出现。

## 直播录制

直播页可以开始录制。录制按 HLS 分片落盘并写 m3u8 索引。也可以把当前直播间设为计划，探测到开播后自动录制。

默认同时录两个直播间，单场最长 4 小时，剩余磁盘低于阈值时自动停止。设置页可以调整限制。

## 设置

设置分为服务、身份、下载、外观、能力、诊断和关于。

- 身份数量和健康状态在“身份”中查看。
- 下载目录和命名模板在“下载”中修改。
- 深浅主题和字号在“外观”中修改。
- “能力”显示当前接口支持情况。
- “诊断”可以查看最近错误和运行日志。

修改即时保存到本机。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 全局显示或隐藏 | `Ctrl+Shift+D` |
| 粘贴链接 | `Ctrl+V` |
| 命令面板 | `Ctrl+K` |
| 返回 | `Esc`、`Alt+←` 或 `Cmd+[` |
| 缩小为迷你窗 | 命令面板搜索“迷你” |

## 数据位置

设置、任务、计划和资料库索引存本机 SQLite。下载、录制和日志写本机目录。

应用不保存账号密码，也不经过项目自建服务器。

## 已知限制

平台、身份风控、接口变化、安装签名和付费内容的限制见 [常见问题](FAQ.md)。
