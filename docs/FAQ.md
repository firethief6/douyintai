# 常见问题

状态：现行
摘要：账号、数据、接口、平台、画质和许可证问答。

## 需要抖音账号吗

不需要。应用在本机生成匿名设备身份，不保存账号密码。收藏、关注等会话能力会受限。

新身份会先经过平台的新设备风控期，通常 1–2 天后恢复。期间直播和评论可能提示稍后重试；旧身份不会因为重启应用而变回新号。

## 数据存在哪

设置、任务和资料库索引存本机 SQLite。下载、录制和日志写本机目录。项目没有自建服务器。

匿名身份文件和租用状态也只写本机，不随安装包分发。

## 会不会上传数据

应用直接请求抖音接口。除接口请求本身外，不上传本地资料。报告问题时主动导出的诊断包由用户自行上传；包内的身份令牌和代理账号会在写入时抹掉。

接口被当前网络限流时可自备出口代理。代理默认关闭，只接管接口请求，CDN 默认直连。

## 为什么接口会失效

接口和签名资源来自抖音客户端，平台升级后可能变化。维护者会跟进，但无法保证即时恢复。

## 支持哪些平台

Linux 已验证；Windows 的安装包启动及 H.264/HEVC 播放已验证，继续预览；macOS arm64 已验证。

Windows 缺少 WebView2 或需要 HEVC 支持时，见 [Windows 播放组件](WINDOWS-MEDIA.md)。

## HEVC 只有声音或没有画面

系统缺少能解码 HEVC 的组件时，播放器会隐藏 HEVC 档位并回退到 H.264 资源。安装 HEVC 扩展后要从托盘完全退出再重新打开应用，仅刷新页面不会重新检测。完整步骤见 [Windows 播放组件](WINDOWS-MEDIA.md)。

## 能否下载 4K 或付费内容

可选平台实际返回的画质档位。付费短剧按接口返回的播放地址处理，不负责解密未授权内容。

## 安装包为什么没有签名

开发者签名会暴露个人证书信息，所以安装包不做开发者签名。构建工具只产生不含身份的 ad-hoc 签名。macOS 用 `xattr -dr com.apple.quarantine` 移除隔离属性；Windows 在 SmartScreen 中点击“更多信息 → 仍要运行”。也可以自行编译。

## 可以商用吗

项目代码是 Apache-2.0，可以商用。随包抖音资源和内容的权利仍归各自权利人。
