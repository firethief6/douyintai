# 架构

状态：现行
摘要：进程分层、签名、数据、身份、代理和并发约束。

## 目标

单机、自包含、无外部运行时。用户安装后只需操作系统 WebView。

## 分层

```text
TypeScript 视图
    │ src/lib/api.ts
    ▼
Tauri 命令
    │
    ├── api_call ───────────────► dycore
    │                              ├── 本机身份池
    │                              ├── 出口代理
    │                              ├── HTTP
    │                              ├── 接口路由
    │                              └── protobuf 解码
    │
    ├── 下载管道 ────────────────► SQLite + 文件系统
    ├── 媒体回环代理 ────────────► 抖音 CDN
    ├── 直播录制 ────────────────► HLS 分片
    └── 资料库 / 回收站 / 日志
```

## 签名运行时

`crates/dysign` 用 `unidroid` 在进程内加载 `libmetasec_ml.so`，生成请求信封头。`vendor/unidroid` 是本地补丁副本。

签名资源放在应用资源目录 `sign/`。开发模式下回退到 `crates/dysign/resources`。应用不签名，Unicorn 直接使用可执行内存，不需要签名 entitlement。

## 数据

- 设置、任务、计划、资产和采集记录存 SQLite。
- 下载和录制写用户指定目录。
- 日志写用户配置目录下的 `.douyintai/logs`，按大小轮转。
- 匿名身份在首次运行时生成，租用状态和健康度只写本机。
- 不保存账号密码。

## 身份

身份由 Rust 在本机生成并动态补池。可用身份低于水位时后台补充，失效、退役或达到使用上限后自动替换。身份按健康度租用，风控类失败进入指数冷却，不会在请求中反复撞同一身份。

设置页提供目标数量、暂停和重建。身份文件按平台写入用户数据目录，升级和重装应用不会依赖随包名单。

## 出口代理

代理由用户自备，默认关闭。启用后按身份绑定出口并短期复用，失败出口指数冷却。代理只接管抖音接口；CDN 默认直连，可单独打开。

代理、身份和签名互不改写：代理只改变出网路径，签名仍按原请求生成。

## 播放

抖音 CDN 对 Referer 和 CORS 有要求。应用在回环地址启动最小 HTTP 代理，补 Referer、透传 Range，并改写 HLS 清单和分片地址。前端只拿回环代理 URL。

## 并发

下载和采集由统一任务管道调度。任务写库，启动恢复，分片按已写长度续传，完成后校验总字节。

## 约束

- 不调用外部 `douyin` 服务。
- 不随包匿名身份。
- 不增加 Python、Node、Java、ffmpeg 运行时。
- 三端共用一套代码。
- 接口能力以路由表和接口路由表为准，不臆造端点。
