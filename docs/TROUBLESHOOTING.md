# 排错

状态：现行
摘要：启动、签名、播放、下载和接口故障的处理步骤。

## 反馈问题时导出日志

1. 打开“运行日志”或“设置 → 诊断”，把日志级别切到 `debug`。
2. 重新执行会出错的操作。
3. 点击“导出诊断包”。
4. 点击“新建 Issue”，写明操作步骤、预期结果和实际结果，并说明是否使用代理；把 ZIP 附到 Issue。
5. 排查结束后切回 `info`。

诊断包包含请求状态、耗时、网络与签名结果。身份令牌和代理账号会自动抹掉；作品 ID、作者名和本机目录会保留，上传前可自行检查。

## 启动后空白

1. 确认使用 `pnpm app` 或安装包启动，不用裸浏览器打开 `index.html`。
2. 打开“运行日志”，点击“打开日志文件”。
3. 确认前端已构建，`dist/index.html` 存在。

## 签名初始化失败

检查应用资源目录中是否有 `sign/libmetasec_ml.so`、`sign/libEncryptor.so`、`sign/rootfs`、`sign/supers.tsv.gz`、`sign/device-seq-cold.jsonl`、`sign/alloc.tsv` 和 `sign/jni.tsv`。

开发模式可设置：

```bash
DOUYINTAI_SIGN_RES="$PWD/crates/dysign/resources" pnpm app
```

## 视频 403 或一直 0 秒

确认回环媒体代理已启动，日志中有 `media` 端口记录。Linux 还需要 WebKit 媒体沙箱关闭，主程序已自动设置。

## HEVC 只有声音或没有画面

1. 确认是 Windows 且已安装 HEVC 视频扩展，安装后从托盘完全退出并重新打开应用。
2. 在播放器画质菜单里选择 H.264 档位，确认画面恢复。
3. 仍无画面时卸载扩展并重启应用，用支持的 H.264 资源观看。

安装、卸载和签名检查步骤见 [Windows 播放组件](WINDOWS-MEDIA.md)。

## 直播不播放

直播清单和分片必须经回环代理。检查代理是否改写 m3u8 地址。WebKit 不支持 MSE 时使用原生 HLS，8 秒无进度会退化为逐片拉取。

## 下载失败

- 检查目标目录剩余空间。
- 检查设置中的并发和单文件上限。
- 403 通常是直链过期，重试会重新签名。
- 断点文件保留在 `.part`，继续任务会从已有长度续传。

## 接口返回空或 429

身份池会按错误码换人重试。连续失败时依次检查：

1. 设置页“身份”是否还有可用身份，冷却或耗尽时可等待自动补充。
2. 当前网络是否限流，必要时在“代理”页配置自备出口并实测。
3. 能力矩阵和最近错误，确认不是上游接口变化。

新生成的身份会经历 1–2 天新设备风控期。直播空包或评论返回 `-99999` 时，先确认身份创建时间，不要反复重建。

## macOS 无法打开

安装包没有开发者签名。执行 `xattr -dr com.apple.quarantine /Applications/抖音台.app`，再右键打开。

## Windows 无法打开

在 SmartScreen 中点击“更多信息 → 仍要运行”。缺少 WebView2 时先安装运行时，见 [Windows 播放组件](WINDOWS-MEDIA.md)。
